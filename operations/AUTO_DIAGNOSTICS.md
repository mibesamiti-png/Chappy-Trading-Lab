# Automatic local acceptance diagnostics

Owner requested eliminating repetitive manual debug buttons and copying a
single report into chat. On startup of a new version, run a fixed seven-step
suite automatically, once per saved version. Includes fresh synthetic ZIP,
installed PyArrow (no installation), synthetic OHLCV and aggregation,
existing synthetic completion receipt, cached ZIP catalog/current file
attributes and repeat of an already owner-approved monthly selection using
the saved parameters with persist=False. Missing optional setup is SKIP,
errors are categorized and later checks continue. No new research, member
reads, 2026 evaluation, external commands from fetched instructions, or
automatic uploads. The monthly check uses the same logical period boundary
and does not establish physical isolation. Existing selection is unchanged.
The report has fixed labels/status/timing only, no tokens, paths, tickers,
raw exceptions or market-derived metrics. Saved locally, copied automatically
on completion (replaces clipboard contents), with a copy/retest dialog.
This is a GUI-integrated worker, not an independent process lock or proof
that startup and clipboard work on the owner's PC. No launcher changes.
