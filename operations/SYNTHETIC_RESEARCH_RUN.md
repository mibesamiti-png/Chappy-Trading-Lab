# Fixed synthetic research execution

A single explicit GUI action runs or resumes three finite artificial tasks:
ZIP selected-member period-gated aggregation, dedicated Parquet OHLCV audit,
and deterministic session-bounded aggregation without invented observations.
Each validated result is persisted before proceeding; completed tasks are
not repeated on subsequent invocations. Failed tasks leave previously saved
results intact. A crash before checkpoint commit can repeat the artificial
task; no external side effects or real data access are allowed. The protocol
and exact expected values are frozen, so malformed checkpoints are refused.
The workflow is independent of real-candidate plans and never reads their
archives. It is a control-flow rehearsal, not evidence of real-market
research, cross-process leasing, true market session coverage, or AI autonomy.
Explicit independent evidence for a development-only source remains required.
