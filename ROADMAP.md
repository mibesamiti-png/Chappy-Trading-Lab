# Research roadmap
Revision 1. All HF Data Library work is academic/educational only. No trading signals, live execution, or real-trading algorithm development using restricted data. Commercial research, if ever authorized, must be a separately governed project using independently licensed inputs.

| Gate | Scope | Acceptance |
|---|---|---|
| R0 (188–190) | Source integrity, coverage, calendar, index | Work reported source archive and index validated; A–J backup archives still unverified |
| R1 (191–192) | Descriptive statistics and reproducibility | Work reported completed; underlying artifacts not independently reviewed by Chat |
| R2 (193) | Audit data lineage, Clean lookahead, calendar and sampling, baseline failure | Document what is and is not identifiable; no unsupported real-time claims |
| R3 (194) | Pre-register research hypotheses on development periods | Fixed sample rules, calendar, missingness, metrics, effect sizes, multiple-test control and stop conditions |
| R4 (195) | Compare temporal aggregation and conditional phenomena on development data | Report all planned tests, negative results and uncertainty; preserve final holdout |
| R5 (196) | Decide if simple research models are justified | Proceed only on robust evidence; otherwise document null finding and stop this branch |
| R6 (197) | Frozen protocol and single final holdout evaluation | Separate owner approval required before opening 2026 holdout |
| R7 (198) | Academic synthesis and closure | Reproducibility, limitations and negative findings; no deployment |

Machine learning is conditional, not a goal in itself. New branches of research require documented justification and owner approval if outside scope. A failure or null result is a valid research outcome.
